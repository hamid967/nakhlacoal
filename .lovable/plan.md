## خطة التطوير الشاملة - النسخة القادمة

### المرحلة 1: تحسينات الأداء والسرعة ⚡
- **تحليل Bundle**: تشغيل `rollup-plugin-visualizer` لرصد الحزم الثقيلة وتقسيمها
- **Service Worker**: إضافة Workbox لتخزين الأصول (الصور، الخطوط، JS) للتصفح الفوري عند العودة
- **تحويل الصور**: ضغط `public/*.jpg` إلى AVIF/WebP عبر `sharp` script
- **تأجيل المكونات الثقيلة**: `InspectionCube`, `Trademarks3D`, `GoldParticles` عبر `React.lazy` + `IntersectionObserver`
- **إزالة CSS غير المستخدم**: تفعيل `tailwindcss purge` بدقة على ملفات الإنتاج فقط

### المرحلة 2: ميزات جديدة للمتجر 🛒
- **سلة شراء مستمرة** (`CartContext` + localStorage + Supabase sync للمسجلين)
- **صفحة Checkout** بمراحل: تفاصيل العميل → الشحن → المراجعة → إنشاء طلب
- **تتبع الطلب العام** عبر رقم الطلب + رقم الجوال (بدون حساب)
- **تقييمات المنتجات** (جدول `product_reviews` مع RLS، نجوم، صور)
- **Wishlist** للمنتجات المفضلة

### المرحلة 3: ترقية لوحة الأدمن 📊
- **Dashboard متقدم**: مخططات Revenue/Orders بـ recharts (يومي/أسبوعي/شهري)
- **إدارة العملاء** الموسعة: تاريخ شراء، LTV، تجزئة (segments)
- **مدير الكوبونات/الخصومات**: كود، نسبة/مبلغ، حد أدنى، صلاحية
- **إشعارات في الوقت الفعلي**: Realtime subscription على الطلبات الجديدة + صوت تنبيه
- **سجل النشاط** (audit log) لكل تعديل من الموظفين

### المرحلة 4: تحديث التصميم والثيم 🎨
- **توحيد المسافات**: مقياس 4/8/12/16/24/32/48/64 فقط
- **Dark Mode كامل** عبر `data-theme="noir"` لكل الصفحات (حالياً جزئي)
- **Micro-interactions**: hover/focus states موحدة عبر `--motion-*` tokens
- **Hero variant جديد**: نسخة "Minimal" بدون 3D للأجهزة الضعيفة (auto-detect)
- **Print stylesheet** للفواتير والتقارير

---

### الترتيب المقترح للتنفيذ
أوصي بالبدء بـ **المرحلة 1 (الأداء)** أولاً لأنها تستفيد منها كل المراحل اللاحقة، ثم **المرحلة 3 (الأدمن)** لتعزيز إدارة الأعمال، ثم **المرحلة 2 (المتجر)** كميزات للعملاء، وأخيراً **المرحلة 4 (التصميم)** كصقل نهائي.

### التقنيات
- Frontend: React + Vite + Tailwind (موجود)
- Backend: Lovable Cloud (Supabase) - جداول جديدة مع RLS + GRANT
- Realtime: Supabase Realtime channels للأدمن
- Storage: bucket جديد للتقييمات والصور

هل تريد البدء بالمرحلة 1 (الأداء) أم تفضل ترتيباً مختلفاً؟ يمكن أيضاً تنفيذ مرحلة واحدة فقط إذا أردت التركيز.
