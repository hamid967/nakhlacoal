## 2. التخطيط — Broken Grid System

شبكة 12 عمود مع كسور مقصودة:
```
┌──────────────────┬─────┬────────┐
│                  │     │        │
│   Hero Image     │  ●  │  Title │
│   (7 cols)       │     │  (4)   │
│                  │     │        │
├────┬─────────────┴─────┴────────┤
│    │                            │
│ 03 │      Editorial Copy        │
│    │      (offset -40px)        │
└────┴────────────────────────────┘
```

**قواعد الكسر:**
- عناصر تخرج عن الشبكة بمقدار ±40px
- أرقام كبيرة (01, 02, 03) كتراكيب زخرفية
- صور بحجم غير متناسق (نسبة 3:4 مع 16:9)
- فراغات بيضاء واسعة (whitespace ≥ 30%)

## 4. الحركة والتفاعل (Motion)

- **Lenis Smooth Scroll** موجود بالفعل ✓
- **Scroll-triggered reveals**: كل عنصر يظهر بـ `opacity 0→1` + `translateY 40→0`
- **Hover على الصور**: `scale(1.03)` + `filter: saturate(1.1)` خلال 700ms
- **الأزرار الذهبية**: gradient shift + subtle glow
- **الأرقام الديكورية**: تدور ببطء (`rotate 0→2deg`) عند الظهور
- **Cursor**: بلا تخصيص (الافتراضي، صحّة الوصول)

## 6. مبادئ إمكانية الوصول

- تباين AAA للنصوص على الخلفيات الداكنة (ratio ≥ 7:1)
- `focus-visible` واضح بحلقة ذهبية (2px)
- تنقل كامل بالكيبورد
- RTL أولوية + `dir="rtl"` على جذر الصفحة العربية
- بدائل نصية (alt) وصفية لكل صورة
- `prefers-reduced-motion` يوقف الحركات المكثفة
